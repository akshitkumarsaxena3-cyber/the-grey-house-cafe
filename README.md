## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any web browser, or serve using Python:

```bash
git clone https://github.com/akshitkumarsaxena3-cyber/the-grey-house-cafe.git
cd the-grey-house-cafe

# Run local server
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
